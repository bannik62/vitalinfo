Mon infrastructure repose sur plusieurs stacks Docker orchestrées :

▶ Stack Codeurbase
   • Backend Express (API REST)
   • n8n pour l'automatisation de workflows
   • phpMyAdmin pour la gestion des bases de données
   • Umami pour l'analytics

▶ Stack Vitalinfo
   • Backend Express avec agent administratif
   • PostgreSQL pour l'historique de chat et les préférences utilisateur
   • MySQL pour les données principales
   • Frontend Svelte

▶ Services locaux
   • Ollama (LLM local) pour des tâches d'IA sans coût externe
   • Apache en reverse proxy avec virtual hosts
   • Let's Encrypt pour le TLS
   • Firewall UFW configuré

▶ Intégrations externes
   • Supabase (base de données)
   • Pinecone (vector database)
